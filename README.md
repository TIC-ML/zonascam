# Para todos los docentes de la pública

Mapa y reparto en zonas de los centros educativos públicos de la Comunidad de Madrid, para organizar
visitas a los centros **sin asamblea docente**, con un sistema sencillo y gratuito de reservas por equipos.

- 🗺️ **Mapa**: centros con asamblea / sin asamblea / sin dato, y zonas coloreadas por nº de profesores.
- 🧭 **Zonas**: grupos de N centros cercanos, sin superponerse, para una mañana. Cada zona se descarga en PDF
  con la dirección y el contacto de sus centros y enlaces a Google Maps y OpenStreetMap.
- 📅 **Reservas**: cada equipo reserva una zona para un día de lunes a jueves.
- 💬 **Telegram**: enlace y QR del canal de coordinación.

Coste: 0 € (GitHub Pages + Google Sheets/Apps Script + OpenStreetMap).
